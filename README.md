# Digitec Galaxus – Produktseiten-Gedankenexperiment

👋 Hallo

Dieses Repository enthält eine **private, inoffizielle Produktseiten‑Spielerei**, die ich als kreativen Gag im Rahmen meiner Bewerbung erstellt habe.

Die Idee war:
> *Was wäre, wenn man sich selbst wie ein Produkt auf einer Galaxus‑Produktseite präsentiert?*

Ziel ist **kein echtes Galaxus‑Design** und keine offizielle Funktionalität,  
sondern ein Gedankenexperiment, das zeigt:
- Verständnis für Produktlogik & Struktur
- Sinn für UI/UX
- Humor & Selbstreflexion
- Motivation, mehr zu machen als nötig
